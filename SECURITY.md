# Security Policy

## Supported versions

Only the latest published version is supported with security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.7.x   | :white_check_mark: |
| < 0.7   | :x:                |

## Reporting a vulnerability

Please **do not** open a public issue.

Use the repository's **Report a vulnerability** button
(Security tab → Advisories) to open a private security advisory,
or contact the maintainer through GitHub.

We aim to acknowledge reports within 7 days and to publish a fix
as soon as possible.

## Scope

This app runs an OpenCode server and a VS Code tunnel in a container,
with optional access to the Home Assistant configuration.
Reports about the container setup, default options, documentation,
or exposed endpoints are in scope.
